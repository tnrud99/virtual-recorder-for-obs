Virtual Recorder for OBS - Windows
==================================

Requires OBS Studio 32.1.2 and Windows 10/11 (64-bit).


INSTALL

1. Quit OBS Studio.
2. Extract the ZIP first (right-click the ZIP > Extract All).
   Install-Windows.bat does not work from inside the ZIP.
3. In the extracted folder, double-click Install-Windows.bat.
   If Windows asks to allow changes, click Yes.
4. Open OBS Studio. If the dock is hidden,
   choose Tools > Open Virtual Recorder.

If a blue "Windows protected your PC" screen appears,
click "More info", then "Run anyway". It appears because the file is new.


PREFER NOT TO RUN THE .BAT FILE?

It only copies one folder, so you can do it yourself.
Quit OBS, copy the "virtuedit-obs" folder into

   C:\ProgramData\obs-studio\plugins\

(create the "plugins" folder if it is missing), then open OBS.


UPDATE      Run the new Install-Windows.bat. It replaces the old version.
UNINSTALL   Run Uninstall-Windows.bat, or delete
            C:\ProgramData\obs-studio\plugins\virtuedit-obs
            Your recordings are not removed.


TROUBLE?

Make sure OBS is fully closed, then try again.
If Windows blocked the files: right-click the ZIP > Properties >
check Unblock > OK, then extract again.
Still stuck? Email help@virtuedit.com with your OBS log
(OBS > Help > Log Files).
